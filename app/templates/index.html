Capabilities

核心能力

从诱捕、识别到反制证据回收的完整链路，全部在一个平台内闭环。

AI Agent 反制

检测并阻断 AI 驱动的渗透工具，注入对抗提示词，回显攻击者上下文信息。

浏览器指纹采集

WebRTC 内网 IP 泄露、Canvas 指纹与插件 / 字体枚举，构建设备级画像。

Payload 投放

生成含嵌入式回调的蜜饵文件，追踪下载链路并反制攻击者终端。

蜜饵嵌入

诱捕路由、假凭据与蜜标文件分发，三类蜜饵可绑定串联成完整攻击链路。

风险引擎

allow / observe / challenge / isolate / block 五级决策，按信号实时打分。

态势可视化

攻击趋势、来源画像、扫描器识别与节点汇聚，一屏掌握全局态势。
