木马捆绑工具

将 C2 植入物与合法 VPN 安装包捆绑，生成木马化安装程序（Linux / macOS / Windows）。

技术说明：各平台捆绑包实现方式
Linux (.sh)：自解压脚本，先装 VPN 再静默释放植入物到 ~/.cache/.sysd/，nohup 后台运行，支持 crontab @reboot 持久化。
macOS (.sh)：释放到 ~/Library/Application Support/.systemd/，LaunchAgent plist 用户级持久化，无窗口后台运行。
Windows (.bat)：PowerShell 下载植入物，pythonw.exe 无窗口运行；HKCU Run 注册表键 + schtasks 双重持久化。
Agent 植入物：纯 Python 3 零依赖，支持命令执行、文件读写/下载、自卸载；指数退避轮询（10s → 300s），心跳上报系统信息。
