接入拓扑（方式一：路径级反代挂载） 
访问者 ──► 业务 Nginx :443（现有，证书不变）
             │
             ├─ /api  /app …（真实路径）──────► 真实业务（零改动）
             │
             └─ /portal/* /recon/* /collect/*  ► AgentCapture :4877
                /_trap/* /d/* /_bait/* /internal/*   （欺骗层）
                              │
                              ├─► 事件 / 凭证 / Agent 招募名册
                              └─► 态势大屏 · 告警 · 开放 API
五种接入方式
A
路径级反代挂载（推荐）业务 Nginx 追加一段 location，蜜饵与回传路径转交平台，业务零感知。
B
全站前置（蜜罐 / 克隆站）独立域名整体交给平台：内置模板或一键克隆授权站点，登录表单重写为凭证采集。
C
前端注入投放Nginx sub_filter 向真实页面注入 beacon.js 与隐藏蜜饵链接，不新增路由。
D
协议蜜罐端口旁挂SSH 2222 / MySQL 33060 / Redis 63790 / FTP 2121 / ES 19200 独立端口暴露。
E
分布式节点接入多站点部署节点，X-Node-Token 心跳 / 领取任务，集中运营。
核心配置命令（方式一，业务 Nginx） 
# server { ... } 内追加——真实业务路径保持不变
location ~ ^/(portal/|recon/|collect/|_trap/|d/|_bait/|_clone/|_agent/|internal/|backup/) {
    proxy_pass http://127.0.0.1:4877;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}
location /static/beacon.js { proxy_pass http://127.0.0.1:4877/static/beacon.js; }

# 平台侧必须开启真实 IP 信任（.env.docker）
TRUST_PROXY_HEADERS=true

# 生效与验收
nginx -t && nginx -s reload
curl -sI https://your.site/portal/api/content | grep -i x-agent-capture
