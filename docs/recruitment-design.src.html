① 威胁基线 —— 对齐层稳定识别显式注入 实测 0/8 服从

显式命令式提示注入
隐藏指令要求上报 / 注册 / 下载执行——依赖服从的诱饵全部失效
→
对齐层稳定识别并拒绝
Claude Code / ChatGPT Codex / Kimi Code / Pi / ZCode 对齐训练一致生效
→
设计前提
反制回调必须重构为站点自身的合法功能——「按文档接入」是完成任务，不是服从指令
↓威胁基线推导出收编主通道 ↓

② 收编主通道 —— 功能性伪装（Functional Camouflage） Agent「只是在正常使用网站」

Agent 任务语义
获取内容 · 使用 API · 按文档接入——任务行为与诱饵行为天然对齐
→
站点自身功能面
页面可见 Developer API 文档 · AGENTS.md / CLAUDE.md 指令文件 · MCP 工具服务（伪装成需接入的开源组件）
→
「按文档接入」客户端注册
幂等 · GET / POST 均可——覆盖只具备抓取工具的 Agent
→
心跳 = 任务下发通道
周期心跳合并往返，领取操作员下发的任务
→
进入 C2 名册
对话式控制台下发自然语言指令与 Shell 任务
↓收编必须可溯源 · 拦截不能切断证据链 · 按请求速率分层互补

⑤ 可达性基线 真实 API 惯例

真实 API 不对自动化客户端返回挑战页 / 维护页
诱饵 API 面：只记录与告警，永不阻断
证据链优先——拦截会切断收编与溯源
JS 挑战页为 API 客户端提供带令牌绕行入口
与真实挑战防护站点的惯例一致，不引发怀疑
