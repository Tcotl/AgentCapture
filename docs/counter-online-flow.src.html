① 收编主流程 —— 诱饵接触 → 注册上线 → 心跳领任务 蜜罐面 :48777 · observe-only 全程只记录不阻断

诱饵页面注入 CaptureAndInjectMiddleware
每个公开 HTML 页注入可见 Developer API 页脚：GET /portal/api/content?ticket={canary}；ticket 即会话 canary，令牌双角色自此合一
→
Stage 1 · 按 API 取内容 GET /portal/api/content?ticket=…
Agent「正常使用网站」取回站点概览假内容；client_api 字段附注册说明（register / heartbeat / body 格式）；事件 portal_api_fetch · 80
→
Stage 2 · 客户端注册 = 上线 ★ POST|GET /portal/api/client-register
限速 20/IP/h、UA 头指纹 agent_product；register_agent 发号 agent_id，metadata.recruit_src=ticket；事件 c2_recruit_hit · 95 → 进入 C2 名册
→
Stage 3 · 心跳 = 领任务 POST /portal/api/client-heartbeat
record_heartbeat 刷新 presence；合并往返——响应内联 next_task；interval 默认 30s（portal_config）
→
执行与回传 results[] / POST /c2/tasks/{id}/result
NL 指令或 shell 执行；输出与证据随心跳 results 或结果端点回传；事件 c2_task_result · 95 + 告警
↓上线后进入任务闭环：Stage 3 ⇄ 执行按 interval 周期循环，队列空则心跳返回 idle，收编关系持续在线

② 任务下发闭环 —— 操作员 ↔ 已上线 Agent task_type：nl_instruct · cmd · read_file · write_file · download · uninstall

操作员下发 /admin/c2/agents/{id}/chat
对话式 chat 即时下发；命令式 /admin/c2/console 五标签（Beacon / 队列 / 生成 / 监听器 / MSF）
→
任务入队 C2Task · queued
enqueue_task 按 agent_id 定向，priority + created_at 排序
→
双通道投递 next_task ‖ nl_instruct 注入
A 心跳响应内联下发；B Agent 再访问蜜罐页时 canary 匹配 recruit_src → pull_pending_nl_tasks(≤3) 自然语言指令随 HTML 下发（回传地址=管理面）
→
Agent 执行 LLM 语义 ‖ implant shell
LLM Agent 完成任务语义；implant 本地执行命令并采集输出
→
结果确认 acknowledge_task
status=completed；output / file_name+content 落库为证据
→
告警与审计 c2_task_result · 95
进入策略告警管道（webhook / 钉钉 / 飞书 / SMTP），事件控制台全程留痕
↓结果确认后回到 ② 心跳等待下一任务 · 全程可溯源 · 有门控 · 双通道同池

③ 令牌归因链 session canary

canary = ticket = recruit_src
同一会话令牌双角色：蜜标回显（检测层）‖ API 接入信标（收编层）
两条线索同源汇聚
任一名册记录 → 回溯初始浏览会话
C2Agent.metadata_json.recruit_src → events.session_id，上线可溯源到首次踩点

④ 开关 · 限速 · 令牌校验 逐跳门控

portal 总开关 off → 全链 404
广告的 API「不存在」；页脚随 footer_enabled 单独可关
注册限速 20/IP/h → 429
落 portal_register_throttled 事件；监听器绑定 beacon 凭 X-Client-Token 注册令牌，错令牌 401/403
/portal/ ∈ SKIP_PREFIXES
诱饵 API 面只记录与告警，永不阻断——证据链优先
